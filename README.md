# Sentinel-AI
A real-time PII masking proxy for LLMs. 

## Features
- Real-time PII masking before data reaches the LLM API.
- Secure bridging between the browser's MAIN world and extension background.
- Local Python backend for processing.

## Setup
1. Clone this repo.
2. Install dependencies using 'pip install uvicorn fastapi'.
3. Load the folder as an unpacked extension in Chrome.
